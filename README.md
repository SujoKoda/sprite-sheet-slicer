# sprite-sheet-slicer
A browser-based sprite sheet slicer. Load a sheet, line up the grid by rows and columns or by frame size, inspect each frame, and export them as a ZIP of PNGs. Vanilla JavaScript and the Canvas API, with no backend or build step. javascript, canvas-api, sprite-sheet, pixel-art, game-development, jszip, vanilla-js, client-side, github-pages
